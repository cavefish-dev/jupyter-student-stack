# Example notebooks

These notebooks show the basics of each language in this environment.
They are **reset every time your server starts**, so they're always up to date.
To keep your changes, copy a notebook into `work/` first.

| Notebook | Kernel | Image |
|---|---|---|
| `00-linux-bash-basics.ipynb` | Bash | all images |
| `01-python-basics.ipynb` | Python 3 | all images |
| `02-java-basics.ipynb` | Java (jjava) | `java`, full |
| `03-javascript-basics.ipynb` | Deno (JavaScript/TypeScript) | `javascript`, full |
| `04-c-basics.ipynb` | C | `c`, full |
| `05-sql-basics.ipynb` | xeus-sqlite | `sql`, full |
| `06-assembly-basics.ipynb` | x86-64 Assembly (NASM) | `asm`, full |
